## Selected Projects

### [MedaIO](https://github.com/p-v-dev/MedaIO)

Go backend API for content management with authentication, PostgreSQL, Docker,
and continuous integration. Its package structure separates HTTP handlers,
use cases, repositories, and infrastructure concerns, demonstrating a focus on
testable backend architecture.

**Stack:** Go, Gin, GORM, PostgreSQL, Docker, GitHub Actions

### [EduQuest](https://github.com/p-v-dev/PIM-IV)

Academic evaluation platform built around a central API and clients for
different institutional roles. The backend handles JWT authentication,
role-based access, questions, exams, attempts, scoring, and rankings, while a
desktop administration client consumes the API.

**Stack:** NestJS, TypeScript, TypeORM, SQL Server, JWT, Swagger, C# / .NET

### [OrçaLink](https://github.com/p-v-dev/OrcaSim)

SaaS application for freelancers to create, share, and manage quotes. It
encodes quote status transitions, public sharing, expiration, plan limits, and
input validation as explicit domain behavior, supported by an automated test
suite.

**Stack:** PHP, Laravel, Blade, Alpine.js, Tailwind CSS, SQLite, Pest, Docker

### [Bundle Valley Co](https://github.com/p-v-dev/BundleValleyCo)

Desktop companion for tracking Stardew Valley Community Center bundles. The
application keeps the interface in React while Rust owns Tauri commands,
validation, and SQLite persistence, providing a clear boundary between the UI
and local application data.

**Stack:** Tauri, Rust, React, TypeScript, SQLite

### [PWA - Construtora Mão de Obra LTDA](https://github.com/p-v-dev/PWA)

Static landing page for a real-world use case, published through GitHub Pages
with GitHub Actions. The project also includes automated checks for its build
and content configuration.

**Stack:** HTML, CSS, JavaScript, GitHub Pages, GitHub Actions
